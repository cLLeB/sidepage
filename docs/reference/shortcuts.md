# Keyboard shortcuts

On a Mac, use <kbd>⌘</kbd> wherever this page says <kbd>Ctrl</kbd>.

## Everywhere

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Go to anything: every command, book and setting by name |
| <kbd>Ctrl</kbd> <kbd>O</kbd> | Open a book or file |
| <kbd>Ctrl</kbd> <kbd>1</kbd> | Written notes |
| <kbd>Ctrl</kbd> <kbd>2</kbd> | Canvas |
| <kbd>Ctrl</kbd> <kbd>3</kbd> | Mind map |
| <kbd>Ctrl</kbd> <kbd>.</kbd> | Focus: hide every bar (again to leave) |
| <kbd>Esc</kbd> | Leave Focus, or Read side by side; close a menu or window |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | Next theme (light, sepia, dark, black) |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>L</kbd> | Next layout (automatic, side by side, book above notes, one at a time) |
| <kbd>Alt</kbd> <kbd>↓</kbd> | Next file in the folder |
| <kbd>Alt</kbd> <kbd>↑</kbd> | Previous file in the folder |

## Reading

| Keys | Does |
| --- | --- |
| <kbd>→</kbd> <kbd>Page Down</kbd> | Next page (e-books, page turning, slides) |
| <kbd>←</kbd> <kbd>Page Up</kbd> | Previous page |
| <kbd>Space</kbd> | Next page (e-books and slides) |
| <kbd>Enter</kbd> in the search box | Next match |

## Writing notes

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Bold |
| <kbd>Ctrl</kbd> <kbd>I</kbd> | Italic |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd> <kbd>Y</kbd> or <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> | Redo |
| `[[` | Link to another book's notes |
| `# ` `## ` `### ` at the start of a line | Headings |
| `- ` at the start of a line | Bullet list |
| `1. ` at the start of a line | Numbered list |
| `- [ ] ` at the start of a line | Checklist |
| `> ` at the start of a line | Quote |
| `$…$` | A formula |

## Flashcards

| Keys | Does |
| --- | --- |
| <kbd>Space</kbd> or <kbd>Enter</kbd> | Show the other side |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>4</kbd> | Again, Hard, Good, Easy |

## Ask AI

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> | Ask |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | New line in the question |
