# Every command

Every command can be run from **Go to…**: press <kbd>Ctrl</kbd> <kbd>K</kbd> (or tap ⌘ on a phone), type a few letters of its name, and press <kbd>Enter</kbd>. Your books are listed there too, by name.

## Go to

| Command | Does | Also in |
| --- | --- | --- |
| Open a book or document… | Pick a file to open | Top bar, **Open** |
| Home: your library | Back to Home | The Sidepage logo |
| Read a web page… | Open an article from the web | Home, ⋯ |
| Open a book beside this one… | A second book in a column of its own | ⫴ at the end of the book's tabs |
| Read side by side, full screen | Two books, no notes, no bars | 📖 at the end of the book's tabs |
| Your folders | The Files panel | Top bar, **Files** |
| Next file in the folder | | <kbd>Alt</kbd> <kbd>↓</kbd> |
| Previous file in the folder | | <kbd>Alt</kbd> <kbd>↑</kbd> |
| Quick notes | Notes that belong to no book | Home, ⋯ |
