# File formats

Every kind of file Sidepage opens, and what you can do with each.

| Kind | Extensions | Notes |
| --- | --- | --- |
| PDF | `.pdf` | Everything: highlights, drawing on the page, clips, picture cards, page map, two pages, page turning, read aloud, search. Scanned PDFs can be made searchable |
| E-books | `.epub`, `.mobi`, `.azw`, `.azw3`, `.kf8`, `.fb2`, `.fbz` | Text size and typeface, highlights, search, read aloud, page turning. Kindle books with DRM (bought from Amazon) cannot be opened |
| Comics | `.cbz`, `.cbr`, `.cb7`, `.cbt` | Page by page |
| DjVu | `.djvu`, `.djv` | Scanned books; a **Dark pages** switch for reading at night |
| Word | `.docx`, `.doc` | Highlights, quotes, look up, translate. The look of complex layouts may differ a little from Word |
| OpenDocument and RTF | `.odt`, `.rtf` | As Word |
| Slides | `.pptx`, `.ppt`, `.pps` | Slide by slide, with page turning |
| Text and Markdown | `.txt`, `.md`, `.markdown` | Markdown is shown formatted |
| Web pages | `.html`, `.htm` | Shown as the page. To read an article from the web, see [Read a web page](/reading/web-pages) |
| Pictures | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.svg`, `.avif` | Zoom, rotate, read the text in them, picture cards |
| A book with its notes | `.sidepage` | Opens the book and puts its notes back. See [Send one book with its notes](/data/backup#send-one-book-with-its-notes) |
| A backup | `.zip` made by **Back up all notes** | Restores your notes. See [Restore a backup](/data/backup#restore-a-backup) |

## Files without an extension

Files from phones and some apps arrive with no extension, or the wrong one. Sidepage looks inside the file to see what it is, so they open anyway.
