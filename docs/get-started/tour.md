# A tour of the screen

Sidepage keeps only what you use all the time on screen. Everything else is one tap away in a menu. This page shows where everything is.

## The top bar

From left to right:

| Button | What it does |
| --- | --- |
| **Sidepage** (the logo) | Back to **Home**, your library |
| **Open** | Open a book or file (<kbd>Ctrl</kbd> <kbd>O</kbd>) |
| **Files** | Your [folders](/reading/folders): open any file in them and move to the next one |
| **Notes** | Your written notes for the book in front of you (<kbd>Ctrl</kbd> <kbd>1</kbd>) |
| **⌄** beside Notes | The other ways of writing: **Canvas** (draw and handwrite) and **Mind map** |
| **Ask AI** | Ask your own AI about the book. See [Ask AI](/ai/ask-ai) |
| **Study** | The study tools: Guide, Review flashcards, All highlights, Papers, Compare two books, Graph of your notes, Study timer |
| **Go to…** | Search for any command, book or setting by name (<kbd>Ctrl</kbd> <kbd>K</kbd>) |
| **🔍** | Search your notes and books |
| **⤢** | Focus: hide every bar and use the whole screen (<kbd>Ctrl</kbd> <kbd>.</kbd>) |
| **⋯** More | Settings, backup, export, updates |

::: tip Cannot find something?
Press <kbd>Ctrl</kbd> <kbd>K</kbd> (or tap **Go to…**, the ⌘ icon on a phone) and type a word such as "timer", "cite" or "backup". Every command in Sidepage can be found this way. See [Every command](/reference/commands).
:::

## The book's bar

Above the book (a PDF here):

| Control | What it does |
| --- | --- |
| **‹ ›** | Previous and next page |
| **3 / 21** | The page you are on. Click it to type a page number and press <kbd>Enter</kbd> |
| **− 82% +** | Zoom out and in. Click the percentage to fit the page to the width again |
| **Contents** | The book's chapters, when it has them |
| **Bookmark** | Bookmark this page, and see your bookmarks |
| **Search** | Find words in the book |
| **Highlight** | Highlight the selected text in a colour, and see your highlights |
| **Quote** | Put the selected text into your notes |
| **⋯ Tools** | Everything else for the book: clip, read the text in a box, picture cards, draw, look up, translate, read aloud, page layout, scroll by itself, turn pages like paper, cite, save a copy |

When something from Tools is switched on (drawing, a clip box, reading aloud), its button stays on the bar so you can switch it off where you are.

## The note's bar

Above the written note:

| Control | What it does |
| --- | --- |
| **↶** | Undo |
| **¶** | Kind of line: plain text, headings, bullet list, numbered list, checklist, quote, and moving or copying the line |
| **B I U** | Bold, italic, underline |
| **A** | Colour of the selected words |
| **Marker** | Run a marker over the selected words |
| **Aa** | Format: strike through, raised and lowered, size, typeface, alignment, plain writing |
| **+** | Insert a picture, table, line, date, link, symbol, diagram or layout |
| **⋯** | Redo, find and replace, read aloud, record sound, spelling and grammar, earlier versions, Word and web page, print, the note's headings, and the paper and writing settings |
| **Saved** | Your note is saved. It says **Saving…** for a moment while you type |

## On a phone

The same controls, arranged for one hand:

- The **top bar** keeps the icons only: Home, Open, Files, Go to, Search, Focus and More.
- **Notes and Study** move to a **bottom bar**, under your thumb. (Ask AI is in the app for computers only.)
- The book and its notes become **tabs**: tap the book's name or **Notes** at the top to switch between them.
- Pinch to zoom the page.

## On a tablet

Held sideways, the book and the notes sit side by side. Held upright, the notes go under the book. You can choose either way for good in **More**, **Layout**. See [Language, theme and paper](/settings/look).

## Panels

Every panel (the book, the notes, Ask AI, the guide) can be moved:

- **Drag a tab** to another side of the screen to put it there.
- **Drag the line** between two panels to make one wider.
- **⤢** at the end of a panel's tab strip fills the window with that panel; click it again to bring the others back.
