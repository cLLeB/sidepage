# Updates

Sidepage keeps itself up to date. You never lose your notes by updating.

## On Windows, Mac and Linux

About a minute after Sidepage starts, it checks quietly whether a newer version is out. If there is one:

1. Sidepage downloads it in the background while you read.
2. A small card appears in the bottom right corner: **Sidepage 0.36.0 is ready**.
3. Click **Restart now**. Your notes are saved first, then Sidepage starts again in the new version. Or click **Not now** and the new version is used the next time you start Sidepage.

Every update is signed. Sidepage checks the signature before installing and refuses anything that was not made from Sidepage's own source.

### Check for updates now

1. Open **More** (⋯ at the top right).
2. Click **Check for updates**.

If you are up to date, Sidepage says so. If not, the update card appears.

### Choose when to update

To be asked before anything is downloaded:

1. Open **More**.
2. Untick **Update by itself**.

Sidepage then tells you when a new version is out, and downloads it only when you click **Update**.

## On Android

About a minute after Sidepage starts, it checks for a newer version. If there is one:

1. A card appears: **Sidepage 0.36.0 is out**.
2. Tap **Download**. The new version downloads in your browser.
3. Open the downloaded file and tap **Install** (Android shows **Update**). It installs over the old version and keeps your notes.

To check now: **More**, then **Check for updates**.

::: warning Coming from a version before 0.35
Versions before 0.35 were signed differently. Back up your notes, uninstall the old Sidepage once, install the new one and restore your notes. The steps are in [Install Sidepage](/get-started/install#android-phone-or-tablet). After that, updates install over each other.
:::

## Web app (iPhone, iPad, Chromebook, browser)

The web app updates itself: when a new version is out, it is used the next time you open Sidepage. There is nothing to do.

## What changed in each version

Every version's changes are listed on the [releases page](https://github.com/cLLeB/sidepage/releases).
