# Make Sidepage your PDF app

Make PDFs (or e-books, Word files, pictures) open in Sidepage when you double-click them. Installing Sidepage never takes a file type away from the app you use now: you choose.

## Windows 11 and 10

**For one kind of file, from the file itself:**

1. Right-click a PDF in File Explorer.
2. Choose **Open with**, then **Choose another app**.
3. Pick **Sidepage**, then click **Always**.

**For several kinds at once:**

1. Open **Settings**, then **Apps**, then **Default apps**.
2. Search for **Sidepage** and click it.
3. Click each type you want (**.pdf**, **.epub**, **.docx**…) and choose **Sidepage**.

If Sidepage is not in the list, update to Sidepage 0.31.1 or later and close and reopen **Settings**.

## Mac

1. In Finder, select a PDF and press <kbd>⌘</kbd> <kbd>I</kbd> (Get Info).
2. Under **Open with**, choose **Sidepage**.
3. Click **Change All…** and confirm.

Repeat for each kind of file (.epub, .docx…) you want Sidepage to open.

## Linux

1. Right-click a PDF in your file manager and choose **Properties**.
2. Open the **Open With** tab.
3. Select **Sidepage** and click **Set as default**.

Names vary a little between desktops (GNOME, KDE, Cinnamon), but the steps are the same.

## Android

1. Open a PDF from your **Files** app, a download or an email.
2. When Android asks which app to use, pick **Sidepage**, then **Always**.

If Android opens it in another app without asking: open **Settings**, **Apps**, the app that opens PDFs now, **Set as default** (or **Open by default**), and tap **Clear defaults**. The next PDF asks again.

## What Sidepage can open this way

Every kind of file it reads: PDF, Word, PowerPoint, OpenDocument, RTF, text, Markdown, web pages, EPUB, Kindle formats, FB2, DjVu, comic archives, pictures and `.sidepage` files. See [File formats](/reference/formats).
